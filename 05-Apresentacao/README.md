# Apresentação

Deck do Projeto Final, na identidade visual do Conecta UFG.

| Arquivo | Para quê |
|---|---|
| [`Apresentacao_Conecta_UFG.pptx`](Apresentacao_Conecta_UFG.pptx) | Editável, para apresentar |
| [`Apresentacao_Conecta_UFG.pdf`](Apresentacao_Conecta_UFG.pdf) | Reserva, caso o PowerPoint não abra na máquina da sala |

## Como está organizado

14 slides, percorrendo o produto e depois o processo.

| Slides | Conteúdo |
|---|---|
| 1 a 5 | O problema com os dados da coleta, o produto e o diferencial |
| 6 a 9 | Etapa 1: ciclo em estrela, técnicas de coleta, requisitos e modelos |
| 10 a 12 | Etapa 2: guia de estilo, princípios indicados e protótipo nos dois perfis |
| 13 | Etapa 3: método de inspeção com as três técnicas |
| 14 | Encerramento com os endereços |

## Tipografia

O guia de estilo usa Nunito. Como ela não estava instalada na máquina onde o
deck foi montado, os slides usam **Segoe UI**, que é o par mais próximo
disponível no Windows. Para trocar: Substituir Fontes, no PowerPoint.
